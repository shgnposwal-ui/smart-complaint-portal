# Smart Complaint Portal

A Smart Complaint Portal developed using Spring Boot, Spring Security, MySQL, and Thymeleaf.

## Features

- User Registration
- Role-Based Authentication (Citizen, Officer, Admin)
- Complaint Registration
- Complaint Tracking
- Complaint Assignment
- Admin Dashboard
- Officer Dashboard

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Thymeleaf
- Lombok
- Git & GitHub
